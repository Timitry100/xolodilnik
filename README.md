# 🧊 Xolodilnik

Telegram Mini App для учёта продуктов в холодильнике: сканирование «Честного знака»,
штрихкодов и текста упаковки, сохранение КБЖУ/состава/срока годности, предупреждения о сроках,
кнопка «Я съел», рецепты нейросетью и список докупки.

📄 **Память проекта и вся документация — в `PROJECT.md`** (обязательно к прочтению).

## Быстрый старт на сервере (Windows)

Двойной клик по **`start.bat`** — сам проверит Node.js, попросит токен бота (если его нет),
поставит зависимости, соберёт приложение и запустит сервер. Внутри него работает **джоб
автообновления**: каждые 2 минуты проверяет GitHub и при новых коммитах сам подтягивает
изменения, пересобирает и перезапускает сервер (см. `PROJECT.md`, раздел 16).

## Быстрый старт для разработки

```bash
# 1. Зависимости
npm run install:all

# 2. Создать server/.env из server/.env.example и вписать BOT_TOKEN

# 3. Бэкенд (терминал 1)
npm run dev:server

# 4. Фронтенд (терминал 2)
npm run dev:app        # http://localhost:5173
```

Для проверки на телефоне — `ngrok http 5173`, адрес указать в BotFather (Menu Button)
и в `server/.env` → `APP_URL`.

## Продакшен (VPS Windows 10)

```bash
npm run build
npm start              # один процесс на порту 3000: API + фронтенд + бот
```

Домен + HTTPS через Caddy (см. `PROJECT.md`, раздел 13).
